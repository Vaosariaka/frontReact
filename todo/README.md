# Dossier todo

Ce dossier contient des CSV prêts à copier-coller dans Excel ou dans ton suivi de projet.

## Fichiers

- `liste_des_taches.csv` : liste complète des tâches par jour, section et statut.
- `groupe.csv` : résumé par jour avec le nombre de tâches faites / à faire.
- `avancement.csv` : indicateurs globaux d'avancement.
- `recap.csv` : résumé simple du projet.
- `detal_avancement.csv` : détail ligne par ligne de l'avancement.

## Utilisation

- Ouvre le fichier CSV voulu.
- Copie le contenu.
- Colle-le dans Excel, LibreOffice ou ton outil de suivi.
- Le séparateur utilisé est `;` pour être compatible avec Excel en français.
