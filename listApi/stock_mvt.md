Champs stock_mvt (PrestaShop)

Endpoint:
- /api/stock_movements/{id}

Exemple (extrait XML):
- <stock_mvt>

Champs principaux utiles en frontend

Champ XML	Utilite
id	identifiant mouvement
id_product	produit associe
id_product_attribute	declinaison du produit
id_warehouse	entrepot
id_currency	devise
management_type	type de gestion
id_employee	employe responsable
id_stock	stock cible
id_stock_mvt_reason	raison du mouvement
id_order	commande associee
id_supply_order	bon de commande
product_name	nom du produit (multilangue)
ean13	code EAN13
upc	code UPC
reference	reference produit
mpn	code MPN
physical_quantity	quantite physique
sign	signe du mouvement (+/-)
last_wa	dernier cout moyen
current_wa	cout moyen actuel
price_te	prix HT
date_add	date creation
